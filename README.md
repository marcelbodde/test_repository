## Doel

Maak de repository begrijpelijk en klaar voor verdere ontwikkeling.

## Werkzaamheden

- Voeg een duidelijke `README.md` toe
- Beschrijf het doel van het project
- Voeg installatie- en gebruiksinstructies toe
- Maak een eenvoudige projectstructuur
- Voeg een passende `.gitignore` toe

## Acceptatiecriteria

- De README legt uit wat het project doet
- Een nieuwe gebruiker kan het project lokaal starten
- Tijdelijke en gegenereerde bestanden worden niet gecommit
